# 多轮压缩策略

**常规做法**：单次 LLM 调用全部重写，或直接丢弃旧内容。

**这里**：

三分区：
1. **Tail**（尾部）：最近 N 轮消息，原文保留（`N` 的取值一般为不超出 LLM 上下文窗口 10% - 15% 的最大值）
2. **Summary**（头部前 50% tokens，按轮次取整，一条用户消息开始到下一条用户消息之前视为一个轮次）：LLM 一次调用，生成结构化锚定摘要，拼凑成第一条消息
3. **Compress**（头部后 50% tokens，按轮次取整）：逐条独立压缩

压缩指令分两类：
- 情感/个人/关系内容 → 逐字保留（原文不动）
- 技术/代码/工具内容 → 概括关键点和流程

压缩触发条件：上下文总 token 数 > 阈值（一般为 LLM 上下文窗口 40% - 80%，上下文窗口大可以取更小的百分比值，上下文窗口小可以取更大的百分比值）
